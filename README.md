# Block Blast - Puzzle Oyunu

Block Blast benzeri cross-platform puzzle oyunu. Windows, iOS, Android ve tüm modern tarayıcılarda çalışır.

## Özellikler

- 🎮 Block Blast oyununun tam klonu
- 📱 Cross-platform desteği (Windows, iOS, Android)
- 🌐 GitHub Pages üzerinden dağıtım
- 💾 Yüksek skor kaydı (localStorage)
- 🎨 Modern ve şık tasarım
- 📲 PWA desteği - mobilde uygulama gibi kurulabilir

## Nasıl Oynanır

1. Blokları sürükleerek oyun tahtasına yerleştirin
2. Satır veya sütun tamamen dolduğunda otomatik silinir
3. Her blok yerleşimi ve satır/sütun temizliği puan kazandırır
4. Blokları yerleştirecek yer kalmadığında oyun biter

## Kurulum

Bu oyun doğrudan tarayıcıda çalışır. Herhangi bir kurulum gerekmez.

### GitHub Pages'te Çalıştırma

1. Bu repository'yi fork edin
2. GitHub Pages ayarlarından `main` branch'ini seçin
3. Oyununuz hazır!

### Yerel Çalıştırma

Sadece `index.html` dosyasını tarayıcınızda açın.
