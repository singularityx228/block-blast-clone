# Block Blast - Puzzle Oyunu

Block Blast benzeri cross-platform puzzle oyunu. Windows, iOS, Android, Pardus ve tüm modern tarayıcılarda çalışır.

## Özellikler

- 🎮 Block Blast oyununun geliştirilmiş klonu
- 📱 Cross-platform desteği (Windows, iOS, Android, Pardus)
- 🌐 GitHub Pages üzerinden dağıtım
- 💾 Yüksek skor kaydı (localStorage)
- 🎨 Orijinal Block Blast teması
- 🏆 Gelişmiş puan sistemi ve combo bonusları
- 📲 PWA desteği - mobilde uygulama gibi kurulabilir
- 🔇 Ses efektleri yok (tamamen sessiz)

## Nasıl Oynanır

1. Blokları sürükleerek oyun tahtasına yerleştirin
2. Satır veya sütun tamamen dolduğunda otomatik silinir
3. Her blok yerleşimi ve satır/sütun temizliği puan kazandırır
4. Combo bonusları ile daha fazla puan kazanın
5. Blokları yerleştirecek yer kalmadığında oyun biter

## Puan Sistemi

- **Blok Yerleştirme:** Blok karmaşıklığına göre puan
- **Satır/Sütun Temizleme:** Her satır/sütun için 10 puan
- **Combo Bonusları:** Ardışık temizliklerde bonus çarpanı
- **Çoklu Satır:** 3+ satır temizliğinde ek bonus
- **Süper Temizlik:** 5+ satır temizliğinde 2x bonus
